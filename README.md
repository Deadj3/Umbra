# Umbra Editor 1.0

A map editor for Project Zomboid Build 42: base, vegetation and zombie spawn maps, a 3D view, a tile library, an annotation map creator, a 3D building editor and a mod export for the Steam Workshop.

The program is in the `app` folder (compiled and obfuscated).
